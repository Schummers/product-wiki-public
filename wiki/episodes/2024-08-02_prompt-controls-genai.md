# Prompt Controls in GenAI Chatbots: 4 Main Uses and Best Practices

## Summary

This article examines UI controls that supplement text input fields in generative AI chatbots. Prompt controls like buttons, toggles, and menus help users expedite prompting, discover AI capabilities, and overcome articulation barriers. Based on research of prominent genAI tools in the US and China, the article identifies four primary uses for prompt controls and provides four best practices to avoid common usability mistakes that hinder discoverability and user understanding.

## Key Takeaways

- **Prompt controls increase discoverability** — visible UI controls around the input field allow users to discover chatbot capabilities without asking "can you" questions, lowering interaction cost.
- **Conversation starters educate new users** — examples of tasks the bot can perform help users understand capabilities and overcome the mental-model gap for those unfamiliar with genAI.
- **Scope constraints improve relevance** — features like Perplexity's Focus allow users to narrow search domains before asking, resulting in more relevant responses and reduced hallucinations.
- **Followup controls enable deeper exploration** — features supporting editing, regeneration, and suggested followup questions facilitate the iterative exploration typical of genAI conversations.
- **Standard design patterns matter most** — using conventional icons with labels or tooltips, clearly naming features, grouping by function, and following existing design conventions significantly improve usability.

## Quotes

> Prompt controls are UI components that surround the input field in an AI-chatbot interface. Their role is to expedite and supplement text input.

> They also facilitate followups. Ultimately, they help overcome the articulation barrier and, thus, lead to more-useful bot responses, benefiting both existing and new users.
