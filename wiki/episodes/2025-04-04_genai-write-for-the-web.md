# Product-Specific GenAI Needs to Write for the Web

## Summary

This article examines how AI-generated content in product-embedded features often violates fundamental web-writing principles, based on a recent usability study. While broad-scope AI tools like ChatGPT produce more scannable content, product-specific AI (like Amazon's Rufus) frequently generates unnecessarily verbose, jargon-heavy, and poorly formatted text that fails to account for user context. The author identifies five key issues: excessive verbosity, poor formatting for scannability, failure to use the inverted pyramid, technical jargon, and lack of user context understanding.

## Key Takeaways

- **Broad-scope AI tools outperform product-specific AI on web writing** — ChatGPT and similar general-purpose tools produce scannable, well-formatted content more reliably than narrow-scope, product-embedded AI tools; product teams must explore finetuning outputs and enforce web-writing best practices.
- **Concision is critical to comprehension** — users read approximately 20% of web content, making brevity essential; AI-generated responses are often unnecessarily long with "fluff" that users must sort through, frustrating participants who need quick, actionable answers.
- **Formatting breaks for scanning are consistently missing** — product-specific AI often includes bullet points but without proper indentation or visual emphasis (bold, italics); users struggle to locate key information in wall-of-text outputs despite structured data being present.
- **Inverted pyramid structure is inconsistently applied** — AI should present need-to-know information first, allowing users to get answers immediately; instead, many responses bury summaries in conclusions, forcing users to read full technical explanations to find basic facts.
- **Jargon and user context mismatch frustrate users** — AI outputs assume domain familiarity even for entry-level questions; AI must learn user context from prompt signals and follow-up questions to match simple prompts with simple responses and technical prompts with detailed explanations.

## Quotes

> Users don't read — they scan.

> "I think it's a lot of information. I'm someone that likes concise information. The question was [...] a yes-or-no question, so [...] that's why I was like 'That's a lot of info for just yes or no.'"

> One of the biggest selling points of generative AI is that it can make us more efficient. But, if AI can't replicate basic rules for writing for the web, it will ultimately fail at that goal.
