# Response Outlining with Generative-AI Chatbots

## Summary

Response outlining is a prompt technique where users include format or structure specifications to guide AI chatbot outputs. Many users adopt this tactic after receiving unsatisfactory initial responses, iteratively refining prompts by adding structural requirements like section headings, numbering, or specific elements (e.g., "include SWOT analysis"). While effective, response outlining creates high cognitive and interaction costs because users must anticipate desired output components before receiving a response, then identify gaps through trial and error. This highlights a key usability challenge: bridging the articulation barrier where users may lack jargon to express requirements or struggle to formulate specifications proactively. GUI enhancements could reduce this burden by suggesting structural options or requesting specifications upfront rather than expecting users to learn through failure.

## Key Takeaways

- **Response outlining uses format specifications in prompts** — users include structural details like numbering, bullet points, or section requirements to shape AI outputs.
- **Iterative refinement is common** — many users discover needed specifications only after receiving inadequate responses, then add them in follow-up prompts.
- **High cognitive and typing effort required** — users must think through all relevant output components and articulate them clearly, which many cannot do from the start.
- **Articulation barrier blocks users** — some users lack the jargon or clarity to specify requirements even when they know what they want.
- **Better UI could reduce friction** — instead of failing first, interfaces could proactively suggest structural elements or ask users to specify preferences upfront.
- **Multiple specifications are more effective than single constraints** — combining structural and format requirements produces better outputs than isolated specifications.

## Quotes

> Response outlining refers to including format or structure specifications in the prompt to ensure that the chatbot's response satisfies those requirements.

> While believed by participants to be an effective strategy, response outlining has a high cognitive load and interaction cost, because it forces users to think about the relevant parts of the expected output and then list them in the prompt.

> GUI elements can be added to chatbots' UIs to create hybrid AI interfaces that reduce users' cognitive load and typing effort.
