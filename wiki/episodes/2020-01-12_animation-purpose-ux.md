# The Role of Animation and Motion in UX

## Summary

Animation and motion in UX should be used with restraint, primarily as a form of subtle feedback for microinteractions rather than for entertainment. While motion attracts user attention through our evolutionary sensitivity to movement, this same property makes animation easy to misuse and can cause distraction and annoyance. Effective animations serve specific purposes: communicating state changes, providing feedback, creating spatial metaphors for navigation, and acting as signifiers for how elements behave.

## Key Takeaways

- **Motion attracts attention** — Our peripheral vision is evolutionarily attuned to detect movement, making us sensitive to any motion in the interface, whether meaningful or not. This attraction means motion easily distracts if used carelessly.

- **Feedback animations are most useful** — Animations should primarily provide noticeable, smooth feedback that an action has been recognized by the system. They help users notice state changes that might otherwise go undetected due to change blindness.

- **State change communication** — Motion can indicate transitions between different interface states or modes, and can provide conceptual metaphors that help users understand mode transitions more clearly than instantaneous changes.

- **Spatial navigation support** — Animations can communicate direction and position within hierarchical information spaces through techniques like zoom-in/zoom-out metaphors and slide-over animations that show progress through processes.

- **Motion as signifier** — The direction and type of animation can signal to users what actions are possible with UI elements, such as which direction an element can be swiped to dismiss it.

- **Avoid gratuitous animation** — Overuse of animation overwhelms and distracts users. Motion should be subtle, unobtrusive, and brief to avoid degrading the user experience.

## Quotes

> In UX, motion and animation can be helpful and communicative, if used with restraint.

> Instead of using animations to provide surface-level delight (that quickly sours), animations can be leveraged for usability: as clues about what is currently happening with the system, as signifiers for how UI elements will behave, and as easily understandable spatial metaphors for the user's location in the information space.

> In summary, when UI animations are subtle, unobtrusive, and brief, they can improve the user experience and can communicate feedback and state changes, prevent disorientation, and strengthen signifiers. But they should not be overused, as they can easily become overwhelming and distract users.
