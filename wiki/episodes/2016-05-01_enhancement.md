# The Role of Enhancement in Web Design

## Summary

An enhancement is a feature that speeds up or enriches interaction for some users but is not essential for task completion. It may also be called an accelerator or shortcut. Progressive enhancement is a web-design strategy offering basic functionality and content to all users, while adding specific additional features on platforms that support them. The concept applies broadly beyond coding to any design serving different user types, devices, or expertise levels. The key principle: enhanced interactions should never be the primary way to access critical features. This article establishes the rule of enhancement and explains how features evolve from enhancements to standards.

## Key Takeaways

- **Two factors determine enhancement status** — Technology capabilities and user abilities; features should be enhancements when only some devices support them or when some users lack familiarity with the interaction method.
- **Technology-based enhancements** — Features should be enhancements when available only on certain devices (e.g., camera-based search on mobile); always provide alternative non-dependent paths (e.g., typed search on desktop).
- **Ability-based enhancements** — When users lack familiarity with an interaction (e.g., swipe gestures), that function should remain accessible through standard UI paths; even familiar interactions may be difficult to execute accurately and need alternatives.
- **From enhancement to standard** — Over time, successful enhancements (like scroll-wheel scrolling) become standard as users learn and adopt them; however, retain older methods as enhancements to support users who prefer familiar behaviors.
- **Two requirements for adoption** — Enhancements become standard if (1) no competing enhancements for the same functionality exist (reduces fan effect) and (2) consistent use across many sites and contexts allows practice and learning.
- **Rule of enhancement** — Enhanced interactions may be implemented, but the UI should not rely on them for any task; redundancy is welcome here, providing shortcuts while maintaining essential accessibility.

## Quotes

> An enhancement is a feature that speeds up or enriches the interaction for some of the users, but is not essential for accomplishing a task.

> Progressive enhancement refers to a strategy of web design that offers basic functionality and content to all users, while enhancing the experience with specific additional features on those platforms (e.g., browsers) that support them.

> Enhanced interactions that take advantage of specific user or device capabilities can be provided, but they should not be the primary way of accessing interface features.
