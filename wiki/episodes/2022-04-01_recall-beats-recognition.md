# Support Recall Instead of Recognition in UI Design

## Summary

This article, published on April Fools' Day, humorously reverses one of Nielsen's 10 usability heuristics that has stood for 28 years: the principle to support recognition over recall. The satirical piece argues that modern users have become lazy due to good UX design, suggesting that recall-based interfaces would exercise users' memory and benefit aging workforces. The article proposes absurd design guidelines like using numeric codes for commands, inscrutable icons, and showing cue cards for only 3 seconds. The humor is deliberate, inviting readers to reflect on how they fell for the arguments and why similarly bad reasoning might persuade stakeholders in real meetings.

## Key Takeaways

- **This is an April Fools' hoax** that does not represent actual usability recommendations.
- **Good design has trained users away from memory use**, and the article ironically suggests forcing memory use as training.
- **90% of usability heuristics remain valid** after 28 years, though specific guidelines can change as human memory and technology evolve.
- **The article reveals when readers realized it was false**, serving as a meta-commentary on how people can be persuaded by outrageous arguments.
- **Recognition over recall remains correct** for modern UI design; this reversal exists only as satire.
- **The satire highlights cognitive science principles** like working memory limitations that support the original heuristic.
