# Indicators, Validations, and Notifications: Pick the Correct Communication Option

## Summary

Systems must keep users informed about system status through appropriate feedback mechanisms. Three distinct communication methods serve different purposes and should be chosen based on information type, urgency, and whether user action is required. Indicators are visual cues (icons, typography, size, animation) making specific UI elements stand out to signal changes; they are contextual, conditional, and passive. Validations are error messages triggered by user input errors; they require user action to correct and apply to specific inputs. Notifications alert users to system events; they may be contextual or global, action-required or passive. Picking the wrong communication method negatively impacts user experience; for example, using passive notifications for error messages leads to missed critical feedback.

## Key Takeaways

- **Indicators are conditional visual cues** — icons, typography variations, size, or animation signal that something special warrants attention about a dynamic UI element or content piece.
- **Validations are error messages tied to user input** — they communicate when data entered was incomplete or incorrect and require the user to take corrective action.
- **Notifications alert users to system events** — action-required notifications interrupt users (modal popups) when urgent action is needed; passive notifications (toast, badge) inform without requiring action.
- **Information type and urgency determine the appropriate method** — validation for form errors, indicators for status changes, notifications for system events; consider whether user action is required.
- **Mismatched communication methods harm usability** — passive notifications for critical errors get missed; modal notifications for passive information frustrate users; indicators should not be used for critical feedback.

## Quotes

> In interaction design, a system, whether an application, website, or piece of hardware (anything from a smartwatch to a thermostat), should always keep users informed, by providing appropriate feedback.

> Ensuring that the state of the system is always visible is one of the 10 usability heuristics for interface design. Information about system status, such as error messages and notifications of system activity, allows users to fully understand the current context.

> Understanding the differences between them will help you sharpen your feedback to users by choosing the best option for each need.
