# Avoid PDF for On-Screen Reading

## Summary

After 20 years of usability research, PDFs consistently degrade the user experience when used for online reading. PDFs are print-optimized, forcing users to scroll through pages designed for paper sizes rather than browser viewports, causing users to get lost and struggle to find information. They also lack web-native navigation features and have slow download times due to heavy file sizes. Organizations continue using PDFs despite these problems because they mistakenly believe PDFs are faster to create than web pages, when maintenance and version control actually favor HTML. The article provides ten evidence-based guidelines for situations where PDFs must be included, with an emphasis on using HTML gateway pages as the primary format for online reading.

## Key Takeaways

- **Never use PDFs for online reading** — PDFs degrade user experience because they are optimized for paper, lack scanning and scrolling affordances, provide only glimpses of content split across paper sheets, and make finding information time-consuming. Twenty years of research confirms this pattern holds consistently.
- **Maintenance favors HTML over PDFs** — Organizations mistakenly assume PDFs are quicker to post online. In reality, updating PDFs requires finding the original file, making changes, ensuring accessibility, saving a new PDF, reposting, and updating all links. HTML CMS updates are faster and preserve links automatically.
- **Create HTML gateway pages instead** — For documents users might print, create an accessible HTML page that summarizes core messages and provides sufficient detail for online reading, with an option to download the full PDF. This gives users the key information in a familiar format without forcing browser-based PDF reading.
- **Apply selective guidelines if PDFs are unavoidable** — If a PDF must be included, gather research evidence users need to print it, make the PDF accessible (searchable text, labeled form fields, proper contrast), minimize file size, provide clear download labels with file size and page count, and remove old versions to prevent outdated information from circulating.
- **Offer multiple formats** — Don't limit users to PDF alone. Provide HTML, e-reader, and audio versions so users can consume content in their preferred format that matches their context and task.

## Quotes

> PDFs are meant for distributing documents that users will print. They're optimized for paper sizes, not browser windows or modern device viewports.

> In reality, it takes more time to manage updates and handle versioning control with PDFs than with webpages.

> With tremendous advancements in web-content management and the ease with which people can publish online content today, there's no reason why we should still see so many PDFs.
