# Similarity Principle in Visual Design

## Summary

The similarity principle states that items sharing visual characteristics are perceived as more related than dissimilar items. This Gestalt principle is foundational for clear UI design, where consistent visual rules for each element type help users understand and use interfaces easily. Each interaction with similar elements develops user expectations for how other similar elements will function. Similarity can unite elements despite distributed placement and is more resilient than proximity-based grouping, though often overpowered by proximity or common region.

## Key Takeaways

- **Principle definition** — Items sharing visual characteristics (color, shape, size) are assumed to be related and function similarly. Similarity doesn't require identical elements, only shared visible traits to signal group membership.
- **Color as powerful unifier** — Shared color stands out prominently and can unite elements of different types, communicating functional similarity. Link color consistently signals clickable elements; however, link color should not be used for nonclickable content.
- **Primary button distinction** — Separate color should be reserved for primary calls-to-action to help them stand out among secondary buttons. When all buttons share the same color, users must spend time determining which is primary.
- **Shape signaling** — Similar shapes indicate related functionality. Rectangles typically indicate buttons; rounded pill shapes indicate navigation links; consistent icon shapes communicate consistent functionality across categories.
- **Size and hierarchy** — Objects sized similarly are perceived as sharing the same level of importance. Using size consistently creates visual hierarchy, making pages easy to scan. Items at different sizes stand out as belonging to different groups.
- **Size pitfall** — When various content types are displayed at similar sizes, they are perceived as related even if different. This causes problems in right rails where content and advertisements appear equally prominent, leading to banner blindness.

## Quotes

> Items which share a visual characteristic are perceived as more related than items that are dissimilar.

> When items share some visual characteristic, they are assumed to be related in some way.

> Same-color buttons will be perceived as sharing the same level of importance.

## Concepts

- [[Gestalt Principles]] — Similarity is one of the original Gestalt grouping principles, discovered in the early 20th century, and remains essential for creating interfaces where relationships between elements are clear and predictable.
- [[Visual Design]] — Applying consistent visual characteristics (color, shape, size, typography) across UI elements creates clear communication about relationships and functionality, helping users develop accurate mental models.
- [[Typography]] — Color and typography are powerful tools for signaling relationships. Link color signals clickability; button shapes signal actionability; and size signals importance. Consistent application prevents misunderstanding.
