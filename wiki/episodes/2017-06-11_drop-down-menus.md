# Dropdowns: Design Guidelines

## Summary

Dropdown menus serve multiple purposes including command selection, navigation, form filling, and attribute selection. While they conserve screen space and prevent invalid input, their overuse creates usability problems. The article distinguishes between dropdown menus (for commands and navigation) and dropdown boxes (for form selection), and provides eight design guidelines to address common issues like long lists requiring scrolling, interacting menus with dependent options, and situations where typing would be faster than selecting.

## Key Takeaways

- **Distinguish dropdowns from boxes** — Dropdown menus are for commands and navigation; dropdown boxes are for form selection. Each has different visual treatment and interaction patterns; using the wrong type for a task creates confusion.

- **Avoid interacting menus** — Do not create dropdowns where options in one change based on selections in another. Users become confused when options appear and disappear; instead present independent option sets or use alternative patterns.

- **Gray out unavailable options** — Keep disabled items visible and grayed rather than removing them; removing items breaks spatial consistency and increases cognitive load as the interface becomes unpredictable.

- **Resist very long dropdowns** — Dropdowns requiring scrolling violate the steering law; users cannot see all options at once and must carefully maintain pointer position. For large option sets, use mega menus, HTML lists, or input fields with validation.

- **Allow typing for familiar data** — For lists like states, countries, or birthdates, allow text input instead of forcing dropdown selection; typing is faster for well-known information.

- **Keep menu labels visible** — Do not hide the dropdown label when the menu opens; labels provide scope and context so users understand what they are selecting among.

## Quotes

> Once you see such confusion in action, you realize that using a "helpful" dropdown menu to save users a few keystrokes can hurt more than it helps.

> Dropdowns do have their advantages. First, they conserve screen space. Because they are a standard widget (even if an unpleasant one), users know how to deal with them.

> Burying your site's top-level categories can be detrimental to user success on any site.
