# Exhaustive Review or "I Can't Believe It's Not There" Phenomenon: Evidence from Eyetracking

## Summary

Eyetracking can distinguish between three types of repeated looking: exhaustive review (confusion), desired exploration (engagement), and necessary review (understanding). Exhaustive review occurs when users return repeatedly to the same area believing content they expect should be there, driven by two reasons: like information should appear together, and web-design conventions set expectations for where elements appear. Deviating from conventions or omitting expected information causes exhaustive review, wasting user time and effort.

## Key Takeaways

- **Three repeated-looking patterns** — exhaustive review shows confusion and wasted effort; desired exploration shows engaged interest; necessary review shows deliberate understanding. Simple fixation counts cannot distinguish between them.
- **Exhaustive review defined** — users revisit areas multiple times believing they missed content, driven by expectations that like information groups together and that UI elements follow web conventions.
- **Grouping expectations** — users expect related content and UI elements to appear together; when basic information is split across page regions, users return multiple times to find expected content.
- **Convention sets expectations** — users learn where things go (e.g., logos in upper left) from years of web use; when conventions are violated, users search familiar locations even after finding content elsewhere.
- **How to avoid exhaustive review** — position related content together, use clear language and labels, follow web-design conventions, and test non-standard designs thoroughly before using them.

## Quotes

> In other words, the person looks at an area, looks elsewhere (maybe on the same page or even on another page), and then returns to looking at the original area.

> People assume that similar content and UI elements will be placed together on the page.

> Exhaustive review happens when people are confused because the page content or the page UI violates users' expectations.
