# Zigzag Image–Text Layouts Make Scanning Less Efficient

## Summary

Eyetracking research comparing zigzag layouts (alternating image-text placement) to aligned layouts (images consistently on one side) shows that layout choice depends on image informativeness. When images provide information, both layouts work equally well because users attend to both. When images are decorative, users in zigzag layouts stumble over images accidentally (residual fixations from scrolling) and redirect, whereas aligned layouts allow smooth text scanning. Unpredictability and complex imagery compound the problem. Aligned layouts for decorative images, high-information first images, and top-aligned text with images work best.

## Key Takeaways

- **Informational value trumps alignment** — meaningful images receive fixations in both layouts; users spend time on both image and text, making layout irrelevant when images have value.
- **Decorative images worse in zigzag** — unpredictability and residual fixations (eye stays in place as page scrolls) cause users to stumble and redirect; aligned layouts allow easier avoidance.
- **Stumbling and redirect behavior** — users encounter decorative images accidentally and must redirect attention to text; zigzag layouts make this redirect more frequent and effortful.
- **Complex imagery compounds problems** — photos containing text, application screenshots, or high detail overwhelm users seeking basic understanding and compete with actual text content.
- **Design strategies** — use aligned layouts for decorative images, place informational content on left side, top-align text with decorative images, avoid complex early images, and ensure every image has purpose.

## Quotes

> Informational value is more important than alignment.

> The zigzag layout is less predictable, making it difficult to scan around image obstacles.

> a lot of accidental fixations can really add up just like clutter in an untidy room, making reading messier and less efficient
