# Universal Navigation: Connecting Subsites to Main Sites

## Summary

Organizations with multiple sites and subsites face the challenge of helping users navigate between them. Universal navigation provides a top-level menu linking subsites back to the main site, ensuring users can escape subsites and reach the main site's homepage. Research shows users get lost in subsites unaware they are in a separate section; universal navigation must balance visibility as a safety exit without distracting from the subsite's own navigation. Six design guidelines ensure usable universal navigation.

## Key Takeaways

- **Universal navigation must appear on every subsite** — Like exit signs in buildings, universal navigation provides a reliable way to escape subsites and return to the main site. Without it, users become lost, frustrated, and may abandon tasks.
- **Keep subsite navigation in visual focus** — Universal navigation should be less prominent than the subsite's global navigation, allowing visitors to explore the subsite without distraction while remaining discoverable when needed.
- **Establish clear visual hierarchy between two navigation levels** — At a glance, users must distinguish subsite navigation (primary, prominent) from universal navigation (secondary, subtle), preventing confusion about which menu controls their current section.
- **Place universal-home link in the top left near logo** — Logo placement in the top left supports users' natural tendency to look there when seeking home. Placing the link nearby (with the domain name, e.g., ESPN.com) leverages users' habitual navigation patterns.
- **Hide universal categories if users rarely switch between subsites** — If visitors focus on one subsite per session, visible category lists waste space. Collapsible menus or dropdowns hide them until needed, reducing cognitive load.
- **On mobile, deprioritize universal navigation** — Space is scarce on mobile. If most users focus on one subsite, move universal links to the bottom of the navigation menu or collapse them, keeping the interface focused and compact.

## Quotes

> Like other secondary navigation schemes such as breadcrumb navigation and utility navigation, universal navigation is an element that most site visitors won't use. That's ok: its role is not to attract clicks. Instead, it should be easily discoverable and accessible when users need it.

> By clearly labeling it and making sure that it does not compete with the local subsite navigation designers can save users time, decrease confusion and frustration, and ultimately improve the user experience.
