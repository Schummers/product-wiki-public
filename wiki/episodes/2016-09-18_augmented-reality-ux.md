# Augmented Reality: What Does It Mean for UX?

## Summary

Augmented reality (AR) is technology that responds contextually to real-world inputs and combines real-world data with programmed interactive elements without restricting user movement. AR differs from virtual reality (which isolates users in fabricated environments) but shares real-time contextual response. AR provides three UX benefits: decreasing interaction cost (information displayed in-context without explicit commands), reducing cognitive load (eliminating need to save information or switch contexts), and combining multiple information sources with minimal attention-switching. Well-designed AR systems can dramatically improve user experience, but poorly designed ones can overwhelm users with information or confusing displays.

## Key Takeaways

- **AR responds dynamically to external inputs** — AR must interpret gestures and actions in real time, account for environmental changes, and present information without restricting users' movements. A static hologram is not AR; a working parking-assistance system is.
- **AR is fundamentally a noncommand interface** — Like other noncommand UIs, AR eliminates the need for users to remember or type commands, reducing interaction cost. An aircraft mechanic inspecting a plane can see part service records displayed in-context rather than accessing a separate system.
- **Three key UX benefits emerge from AR** — Decreases interaction cost (information appears automatically without user action), reduces cognitive load (no need to memorize part numbers or context-switch to lookup systems), and minimizes attention division when multiple information sources are combined into one visual overlay.
- **Context and timing determine interaction** — The same gesture (shake) is interpreted differently based on proximity to a store, participation in an event, or proximity to a song, allowing rich contextual interactions without explicit commands.
- **Good design remains essential** — Well-designed AR systems improve user experience, but poorly designed systems can overwhelm users with irrelevant information, confusing displays, or information clutter, proving that UX professionals have long-term job security regardless of technology changes.

## Quotes

> AR has seen massive success in recent years and is an opportunity for a seamless, low-effort, yet rich user interaction with the real world.

> We're sure that there will be many lousy AR systems shipped in the coming years — that's why UX professionals have long-term job security, despite changes in technology.
