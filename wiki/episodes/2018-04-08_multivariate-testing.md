# Multivariate vs. A/B Testing: Incremental vs. Radical Changes

## Summary

Multivariate testing (MVT) allows designers to test multiple design elements simultaneously and measure interactions between them, determining the optimal combination of variants. Unlike A/B testing which compares completely different designs, MVT refines specific elements to find incremental improvements. MVT requires larger traffic samples to achieve statistical significance because traffic is divided among many variation combinations. MVT is best used after radical redesigns have been validated with A/B testing to refine winning designs.

## Key Takeaways

- **Core purpose** — multivariate testing determines which combination of design variants produces the highest conversion rate by testing all possible combinations simultaneously.
- **Variable and variant terminology** — variables are UI elements (like images or button labels), variants are different versions of each variable, and variations are the complete designs combining one variant of each variable.
- **Interaction measurement** — MVT reveals how elements interact; sequential A/B tests cannot discover that the optimal combination may differ from what individual element tests suggest.
- **Traffic requirement limitation** — the number of variations multiplies quickly (2 variables with 2 variants each = 4 variations), requiring significantly more traffic and longer test duration than A/B testing.
- **Incremental refinement use** — MVT best refines existing successful designs rather than test radical changes; use A/B testing for major redesigns, then MVT to optimize the winning design.

## Quotes

> A multivariate test can help you decide which combination of these design choices would optimize conversions.

> The main advantage of running a multivariate test rather than an A/B test is the ability to determine how various elements on a page interact with one another.

> All combinations of the variants must make sense together. For example, when testing variants of an image and of a headline on a page, don't write headlines that refer to details of an image variant (such as "Great Spa Vacations" vs. "Great Beach Vacations" with corresponding photos), because each headline will accompany each image in a variation for the test.

## Concepts

- [[Analytics]] — using MVT to quantify the performance impact of different design element combinations on conversion goals.
- [[Research Methods]] — choosing appropriate testing methodologies based on whether the goal is radical redesign validation (A/B) or incremental optimization (MVT).
- [[Design Optimization]] — systematically improving specific UI elements through controlled testing to maximize business outcomes.
