# A Concrete Definition of an AI Agent

## Summary

The term "agent" is applied to everything, causing confusion. Nielsen Norman Group proposes a concrete definition: an AI agent is a system that pursues a goal by iteratively taking actions, evaluating progress, and deciding its own next steps. An LLM that responds once is not an agent; an agent must have self-direction and capability to act. Self-driving cars, coding agents, and search agents all qualify. Most useful agents in 2026 are built on LLMs but need tools, external actions, and a feedback loop to function as agents. Usefulness depends on whether the agent reliably understands goals, adapts when things fail, and minimizes required human intervention.

## Key Takeaways

- **Five components** — Agent pursues a goal, iteratively takes actions, evaluates progress, decides next steps, and carries forward context across steps.
- **Not just an LLM** — An LLM is the reasoning engine; an agent is the system built around it with tools, actions, and an iterative loop.
- **Self-direction distinguishes** — Unlike automated systems following predetermined rules, agents decide their own next steps based on what has happened so far.
- **Usefulness criteria** — A useful agent reliably understands goals, adapts to failure, and minimizes human review needed. Usefulness is context and task-dependent.
- **Both execution and judgment** — Agents can fail by doing things poorly (bad execution) or by making poor design decisions (bad judgment) about what to attempt.
