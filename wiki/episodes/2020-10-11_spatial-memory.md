# Spatial Memory: Why It Matters for UX Design

## Summary

This article explains spatial memory, the ability to recall the location of things in user interfaces, and how it affects UX design. Spatial memory allows users to quickly locate controls without visual search and is essential for efficient interaction. The article examines how users develop spatial memory through repeated exposure to stable interfaces and provides design guidelines to support users in building and using spatial memory.

## Key Takeaways

- **Spatial memory definition** — The ability to learn the location of objects through repeated interaction, which allows users to develop automaticity when accessing frequently used features without laborious visual search.
- **Memory is relative** — Users develop spatial memory in reference to boundaries (edges, borders) and landmarks (prominent, easily located objects), not absolute positions.
- **Stability is critical** — Avoiding adaptive interfaces that rearrange elements, and scaling rather than reflowing layouts, helps users maintain spatial memory across sessions.
- **Memory is fuzzy** — Users remember neighborhoods of items rather than exact locations, and only the most frequently accessed items develop accurate spatial memory with enough repetition.
- **Design support strategies** — Use broad, shallow hierarchies, add visual labels and thumbnails, include information-space overviews like minimaps, and create artificial landmarks to support spatial memory.

## Quotes

> In graphical user interfaces (GUIs), this capability is absolutely essential, as it allows users to quickly locate controls without undergoing laborious visual search each time.

> Users develop spatial memory in *reference* to **boundaries** and **landmarks**.

> Except for the most-accessed objects, spatial memory tends to be fuzzy: users don't remember the exact location of an object, but rather an approximation.

## Concepts

- [[Spatial Memory]] — the ability to recall object locations by interacting with them repeatedly, enabling efficient UI navigation through memory of neighborhoods rather than exact positions.
- [[Navigation Design]] — organizing interface structure to support users' spatial memory through consistent layouts, clear boundaries, and hierarchical organization.
- [[Interface Stability]] — maintaining consistent element positioning across sessions and viewport changes to allow users to develop and rely on spatial memory rather than requiring constant visual search.
