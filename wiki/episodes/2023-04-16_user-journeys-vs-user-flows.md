# User Journeys vs. User Flows

## Summary

User journeys and user flows are complementary UX tools used to capture and optimize how people accomplish goals with products or services. Both are structured around user goals and examined from the user's perspective, but they differ significantly in scope and detail. User journeys describe high-level, holistic experiences across multiple channels and over extended time periods, while user flows zoom in on specific, discrete interactions within a single product. Understanding and using both together provides a complete picture of the user experience.

## Key Takeaways

- **Different scope and focus** — User journeys provide macro-level views across channels and time, while user flows provide micro-level views of interactions within a single product, requiring different research methods.
- **Journey maps tell stories** — Effective journey maps communicate not just the steps taken but also user emotions and thoughts, making them narrative and descriptive rather than purely transactional.
- **Context methods for journeys** — Research methods like field studies and diary studies are best for uncovering longer-term user goals and behaviors needed for accurate journey mapping.
- **Usability testing for flows** — User flows are best documented through usability testing, which allows researchers to watch users interacting directly with the product under guided scenarios.
- **Combined approach is powerful** — Using both together allows teams to understand both macro- and micro-level experiences, with user flows providing deep dives into specific areas of the overall journey.
- **Organizational gap** — Most teams lack systematic processes to connect journey and flow views, creating opportunities for teams that can effectively integrate both perspectives.

## Quotes

> User journeys describe a user's holistic, high-level experience across channels and over time. User flows zoom in to describe a set of specific, discrete interactions that make up a common user pathway through a product.

> Examining user journeys and user flows together provides greater context and understanding of users' experiences.

## Concepts

- [[Customer Journey]] — Describes the high-level, scenario-based sequences users take across multiple channels and over time to accomplish goals, requiring emotional and contextual understanding.
- [[User Flow]] — Details the specific, discrete interactions and steps within a single product needed to accomplish common tasks, focusing on the ideal pathway through screens.
- [[UX Mapping Methods]] — Techniques for capturing and communicating user experiences through artifacts like journey maps and wireflows that help teams understand and optimize user experiences.
