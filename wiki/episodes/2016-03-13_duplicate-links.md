# The Same Link Twice on the Same Page: Do Duplicates Help or Hurt?

## Summary

Duplicate links on the same page are generally a bad idea despite good intentions. Redundant links increase interaction cost, deplete user attention, overload working memory (users wonder if the links are different), waste time when clicked twice, and create confusion. While organizations offer legitimate reasons for duplication (safety nets, handling long pages, visual balance, analytics), these problems are usually better solved through design alternatives. The single exception is combining graphical and text elements as one perceived link (like photo + label), which users treat as a single unit rather than redundancy.

## Key Takeaways

- **Redundancy increases cognitive load** — each duplicate link requires processing; users must decide if links are the same or different, wasting mental effort and time.
- **Attention is zero-sum** — extra links compete for user attention; adding redundancy to one link depletes attention available for others.
- **Multiple visits waste time** — users sometimes don't recognize they've already visited a destination, causing wasted repeat visits.
- **Duplicates hurt despite traffic analytics** — analytics showing increased traffic to a page with duplicate links are misleading; that traffic may simply come from reduced clicks elsewhere, and users get confused and less efficient overall.
- **Choose prominence over repetition** — if a link is important, give it more visual prominence, space, and prominence rather than duplicating it.
- **Place duplicates far apart** — if duplication is justified, ensure links cannot be seen together on one screen; if they appear simultaneously, it signals excessive redundancy.

## Quotes

> In many situations, it's better to streamline your interface with few clear choices than to offer more links intended to capture a broader audience.

> Only show what's needed. Nothing more.

> Users often wonder if there is a difference that they missed. In usability studies, we often observe participants pause and ponder which they should click.
