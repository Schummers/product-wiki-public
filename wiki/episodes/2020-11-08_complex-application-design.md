# 8 Design Guidelines for Complex Applications

## Summary

This article presents eight design guidelines for complex applications that support specialized workflows and highly trained users. Complex applications face shared challenges despite domain differences, such as supporting both learning and expertise, managing large datasets, and preventing high-impact errors. The guidelines address making applications learnable through doing, helping users adopt efficient methods, providing flexible workflows, reducing clutter, and making critical information visually salient.

## Key Takeaways

- **Promote learning by doing** — Allow users to learn through trial and error without losing work or causing damage, using techniques like real-time dashboard previews to show immediate results of user actions.
- **Support efficient methods** — Use in-context learning cues and tooltips to help experienced users discover faster, more efficient methods rather than relying solely on tutorials or manuals.
- **Provide flexible pathways** — Avoid rigid, linear workflows; allow users to skip ahead, loop back, or move fluidly between steps to support the nonlinear, exploratory work of complex tasks.
- **Track actions and thoughts** — Enable users to record their reasoning and actions through annotations or comments to offload working memory and support task resumption after interruptions.
- **Reduce clutter without reducing capability** — Use staged disclosure to show options only when relevant, preventing feature overload while maintaining access to advanced functionality.
- **Coordinate tool transitions** — Support switching between multiple applications by providing export functions and integration points, reducing the burden of tool-switching in complex workflows.
- **Ease information transitions** — Help users move between primary and secondary information levels by using hover tooltips and contextual displays without forcing navigation away from primary screens.
- **Make information salient** — Ensure critical elements stand out through both emphasis and removal of clutter, helping users locate important data quickly during visual search.

## Quotes

> Despite the great variance, many of the same challenges exists across all complex applications, both for practitioners creating these complex applications and the end users relying on them for their work.

> Users prefer to start using it immediately, undeterred by its level of complexity.

> Help users manage the choice, feature and function overload prevalent within complex applications by minimizing the appearance of clutter within the interface without reducing the capability of the application.

## Concepts

- [[Complex Applications]] — specialized software serving highly trained users with broad, unstructured goals and nonlinear workflows, requiring distinct UX approaches from consumer applications.
- [[Expert Users]] — skilled professionals who need efficiency and advanced features; complex applications must support both learning for new users and accelerators for expert users.
- [[Information Architecture]] — organizing interface structure and information access in complex applications to reduce clutter, support learning, and enable quick access to critical data without overwhelming users.
