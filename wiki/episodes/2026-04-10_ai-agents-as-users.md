# AI Agents as Users

## Summary

AI agents now interact with digital interfaces designed for humans, navigating websites, filling forms, and executing transactions. This makes them functional users of our interfaces, requiring a conceptual shift: "user" is no longer synonymous with "human." Agents interact using three approaches: vision-based (screenshot + vision model), accessibility-tree parsing (reading semantic structure), or direct API access. Interfaces built with accessibility best practices are already agent-friendly. In the near term, the design question is serving both human and agent users; longer term, interface layers may diverge, with dedicated APIs for agents and visual interfaces for humans.

## Key Takeaways

- **Agents are users** — Agents have goals, encounter interfaces, and attempt to accomplish goals through them; when interfaces fail agents, they fail the humans who delegated to them.
- **Three interaction approaches** — Vision-based is expensive and error-prone; accessibility-tree parsing is cheaper and more reliable; direct APIs bypass interfaces entirely.
- **Accessibility as business case** — Investing in semantic HTML, clear labeling, predictable patterns, and proper ARIA is now both ethical and pragmatic, enabling agent navigation.
- **Not all products want agents** — Some models depend on human visits (ad-supported sites), some require friction for regulatory reasons, some guard competitive intelligence, some want to be the intelligent layer.
- **Competitive risk of opting out** — Blocking agents carries risk if competitors enable them; strategic choice, not universal imperative.
