# Local Navigation Is a Valuable Orientation and Wayfinding Aid

## Summary

Local navigation shows users their current location in a website's hierarchy and provides access to related sibling pages and child pages within the current category. While global navigation (top tier) remains constant across the entire site, local navigation changes contextually based on the user's current page. Local navigation serves three purposes: indicating current category location (orientation), showing related pages users can access (wayfinding), and providing low-interaction-cost access to deep content. Local navigation is most beneficial for sites with large hierarchies where users engage in exploratory browsing rather than known-item search. Design considerations include placement (horizontal below global navigation or vertical on left side), visibility (noticeable but less salient than global navigation), and depth (typically 2-3 tiers maximum before switching to breadcrumbs).

## Key Takeaways

- **Three Functions** — Local navigation provides orientation (shows current location), wayfinding (shows adjacent pages), and deep-content access at low interaction cost.
- **Hierarchical Complement** — Global navigation shows top tier and stays constant; local navigation shows current branch and varies by location, working together to display full hierarchy.
- **Appropriate for Large Sites** — Small sites with few pages don't benefit from local navigation; deep sites with many pages per category benefit, but very deep hierarchies exceed local-navigation UI capacity.
- **Exploratory Browsing** — Local navigation supports users who browse multiple pages within a category to explore options, compare information, or find exactly what they need.
- **Placement Decisions** — Horizontal placement below global navigation is compact; vertical on left side takes more space but supports deeper hierarchies; choice depends on IA breadth and depth.
- **Depth Limitations** — Horizontal local navigation typically supports 2-3 tiers; vertical indenting in deep architectures loses space quickly; breadcrumbs are more compact for deeper pages.
- **Visual Hierarchy Balance** — Local navigation must be visible (discoverable) but less salient than global navigation; if local appears more prominent, users mistake it for the main navigation.

## Quotes

> Local navigation is a type of navigation that is contextual to the user's current location — showing sibling pages within the current category, and if applicable, the children or nieces and nephews of the current page.

> These same behaviors of orientation and wayfinding exist for users of websites, and, like in the city-navigation example, the kinds of cues that help users will depend on their information-seeking needs.

> Local navigation should not be more salient than the global navigation, because, if that happens, users may mistake the local navigation for the global one.

## Concepts

- [[Navigation Design]] — Global and local navigation must work together, with local navigation design decisions depending on site hierarchy and user browsing behaviors; local navigation enables efficient wayfinding by showing adjacent content users can reach from their current location.
- [[Information Architecture]] — Hierarchical IA structure determines whether local navigation is appropriate and how many tiers can be shown effectively.
- [[Orientation]] — Local navigation provides "you are here" indication, helping users understand their position in the site hierarchy.
- [[Visual Hierarchy]] — Visual distinction between global and local navigation must reflect information hierarchy importance; local navigation should be noticeably subordinate.
