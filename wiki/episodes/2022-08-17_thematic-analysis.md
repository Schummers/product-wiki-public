# How to Analyze Qualitative Data from UX Research: Thematic Analysis

## Summary

Thematic analysis is a systematic method for organizing rich qualitative data by tagging observations and quotations with codes, then discovering significant themes through iterative comparison. The method helps researchers overcome common challenges like data overwhelming, superficial analysis, contradictions, and analysis that merely regurgitates rather than interprets participant feedback. Three main approaches exist: using analysis software like Dovetail or Dedoose, manual journaling with memos, and affinity diagramming with physical or digital grouping. Regardless of method, the six-step process involves gathering data, reading everything, coding text, identifying themes, taking a break for fresh perspective, and evaluating themes for good fit. Codes can be descriptive (what the data is about) or interpretive (analytical reading with researcher's lens), and themes emerge when related findings appear across multiple participants.

## Key Takeaways

- **Systematic process prevents wasted effort** — Without structure, analysis becomes superficial skimming, focuses on memorable events, produces description without interpretation, and ignores contradictions; thematic analysis provides discipline and focus.
- **Code definition and consistency** — A code is a shorthand label for text segments; codes should have descriptions and examples, especially when multiple people code, to maintain consistency and allow comparison of text segments about the same topic.
- **Two code types serve different purposes** — Descriptive codes capture what data is about while interpretive codes add the researcher's analytical reading; both types are useful and can be assigned during or after grouping.
- **Six steps ensure rigor** — Gather all data, read everything from beginning to end, code by asking "what is this about?", create new codes that encapsulate potential themes, take a break for fresh perspective, and evaluate themes for support and saturation.
- **Team involvement improves analysis** — Workshops where team members read transcripts and highlight important sections build empathy for users and ensure shared understanding; having others evaluate themes reduces personal bias.
- **Iterative analysis matters** — Themes should be scrutinized for whether they are well-supported by data, saturated with many instances, and agreed upon by others; if not, return to the analysis board rather than forcing conclusions.

## Concepts

- [[Qualitative Research]] — Thematic analysis is a systematic method for making sense of large volumes of qualitative data through iterative coding and theme identification across participants.
- [[Coding]] — Assigning labels to text segments allows researchers to group similar observations and identify patterns; codes can be descriptive (what) or interpretive (analytical).
- [[Thematic Analysis]] — A structured six-step method that prevents superficial analysis, ensures all data is considered, and uses iterative comparison to uncover meaningful patterns.
- [[Data Analysis]] — Thematic analysis transforms raw observations into organized themes by grouping coded segments and identifying relationships, similarities, differences, and causal patterns.
- [[Grounded Theory]] — Journaling-based thematic analysis uses memos and manual annotation following grounded-theory methodology, providing a flexible and cheap approach that documents the analytical journey.
