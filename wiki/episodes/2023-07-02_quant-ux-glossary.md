# Quantitative UX: Glossary

## Summary

This glossary provides definitions for essential terminology used in quantitative UX research and data analysis. Covering approximately 45 terms organized alphabetically, the glossary addresses core concepts including study design (between-subjects, within-subjects), variable types (independent, dependent), metrics (performance, self-reported, categorical, continuous), statistical measures (confidence intervals, standard deviation, p-values), survey instruments (Likert scale, NPS, SUS), and validity concepts. The glossary serves as a reference for UX researchers conducting quantitative studies and analyzing the resulting data.

## Key Takeaways

- **Study design determines statistical analysis** — choosing between-subjects (different participants per condition) and within-subjects (same participants test all conditions) designs affects participant recruitment needs, study session length, and the statistical tests applicable to data.
- **Multiple metric types serve different purposes** — performance metrics capture user behavior, self-reported metrics measure perception, and metrics can be categorical, continuous, discrete, or binary, each requiring different analytical approaches.
- **Confidence intervals and margins of error convey result precision** — these related concepts help researchers communicate the likely range where the true population value falls, influenced by sample size and confidence level chosen.
- **Validity dimensions matter for study credibility** — internal validity ensures the study setup is fair to all conditions, while external validity ensures the study setup and participants reflect real-world situations.
- **Common survey instruments enable comparison** — standardized instruments like the System Usability Scale (SUS), Net Promoter Score (NPS), and NASA Task Load Index (NASA-TLX) allow benchmark comparisons across studies and organizations.
