# Listboxes vs. Dropdown Lists

## Summary

This article defines listboxes and dropdown lists, discusses when to use each element, and provides decision criteria based on design context. While both elements allow selection from a constrained set of options in a compact space, they differ in visibility, interaction cost, and ability to support multiple selections. The article provides detailed guidance on matching controls to specific scenarios involving option counts, selection types, and user needs.

## Key Takeaways

- **Listbox Definition** — a container with a visible list of items from which users can select one or multiple items; items may be scrollable depending on quantity and viewable area.
- **Dropdown List Definition** — a compact control showing a single default or selected value with a down-arrow button; clicking reveals a mutually-exclusive item list; selecting or clicking outside closes it.
- **Listbox Advantages** — low interaction cost (options visible without clicking), increased visibility enabling faster decisions, support for single and multiselection, support for reordering in dual-listbox variants.
- **Listbox Disadvantages** — take more screen space than dropdowns, less familiar to general web users, multiselect via keyboard modifiers (Control/Shift) often unknown requiring checkboxes, may hide selected items if many options exist.
- **Dropdown Advantages** — take minimal space, familiar to most users, allow default optimal values, work well to downplay alternatives for nonexpert users.
- **Dropdown Disadvantages** — require click to reveal options, prone to overstuffing with scrolling required, slow users for readily-known values (dates, credit card expiration), may be overlooked in forms, easy to dismiss with cursor deviation.
- **Selection Criteria** — use listboxes with 5-15 options when space available; use dropdowns with 5-15 options when space limited; use listboxes for multiselection; use radio buttons/checkboxes for 5 or fewer options.

## Quotes

> Listboxes and dropdown lists make a form compact — especially when many options are available, and presenting those options as a list of standalone radio buttons or checkboxes would take up an unnecessary amount of screen space. Using a listbox or a dropdown list can also reduce errors by constraining the options to those in the list and ensuring that users enter data in the proper format.

> Compared to using standalone checkboxes or radio buttons, it's better to use a listbox or dropdown list when there are 5 or more items from which users can choose.

> When including a listbox or dropdown list in your design, always display the options in a logical order.
