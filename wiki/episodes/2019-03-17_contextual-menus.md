# Contextual Menus: Delivering Relevant Tools for Tasks

## Summary

This article defines contextual menus as UI elements that appear on demand with a small set of relevant actions related to a specific control, interface area, or data selection. Contextual menus reduce interaction cost and cognitive load by presenting only task-relevant actions without requiring users to parse full menu systems. The article covers menu triggers (right-click, long-press, swipe), best practices for effective implementation, and platform-specific considerations for desktop and mobile applications.

## Key Takeaways

- **Include only task-relevant actions** — Contextual menus should contain a focused set of options directly related to the selected element or task; include global actions like Save or Print only when truly relevant.
- **Make actions available multiple ways** — Ensure all commands in contextual menus are also accessible from main navigation, since hidden menus aren't discoverable to all users.
- **Add visual indicators for discoverability** — Use ellipsis buttons or down arrows to signal that contextual menus exist; not all users know how to trigger them through gestures or right-click.
- **List commands by frequency of use** — Organize actions from most to least common so users can quickly find relevant options without scanning the entire list.
- **Limit menu length to avoid scrolling** — Keep contextual menus to fewer than ten to twelve items to avoid choice overload and ensure all options are visible.
- **Disable irrelevant options rather than hiding** — When actions aren't relevant in current context, disable rather than hide them so users understand why options aren't available.

## Quotes

> A contextual menu is a type of menu that appears on demand and contains a small set of relevant actions related to a control, an area of the interface, a piece of data in the application, or a view of the application.

> Offering a small subset of relevant actions in contextual menus helps users find exactly what they need for the task at hand.

> Contextual menus exist across all operating systems, in both desktop and mobile applications.
