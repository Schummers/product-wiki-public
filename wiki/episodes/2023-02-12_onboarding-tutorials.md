# Onboarding Tutorials vs. Contextual Help

## Summary

This article examines why traditional onboarding tutorials are ineffective despite seeming like a logical way to teach users how to use software. The author presents research and real-world examples showing that push revelations (unprompted tutorials and feature announcements) interrupt users, are hard to remember, and don't improve task performance. The article advocates for pull revelations, which are contextual help triggered by signals that users need information at that specific moment, supported by guidelines for implementing them effectively.

## Key Takeaways

- **Push revelations are counterproductive** — unprompted tutorials shown when apps launch interrupt users who want to start using the product immediately, leading them to skip the help or forget what they learned.
- **Users suffer from cognitive overload** — tutorials present information out of context, forcing users to memorize steps for later use rather than applying them immediately, which exceeds working memory capacity.
- **Pull revelations work better** — help content triggered by user actions (like hovering over tools or attempting new features) is more effective because it addresses the user's immediate need at the right moment.
- **Context matters for help effectiveness** — good contextual help requires understanding when users will actually interact with a feature and what signals indicate they need guidance.
- **Progressive disclosure aids learning** — making help visible but not overwhelming by default, with options to expand for more detail, respects both novice and experienced users.
- **Memorization should be avoided** — for multi-step workflows, help should appear alongside each step rather than requiring users to retain information in working memory.

## Quotes

> Push revelations reveal new information out of context, without any specific indication that the user would benefit from the information at that moment.

> Pull*revelations are help content triggered by some signal that the user would benefit from that information at that moment.

> No memorization! For multistep workflows, make sure that the help content doesn’t require the user to keep lots of information in their working memory — show help content alongside each step to minimize cognitive load.

## Concepts

- [[Onboarding]] — onboarding tutorials are often misused as push revelations that interrupt users, but contextual help is more effective for teaching new interfaces.
- [[Contextual Help]] — help content triggered by user actions at the moment of need is more effective than unprompted tutorials for supporting user learning.
- [[Interaction Design]] — designing help systems requires understanding user workflows and signals indicating when help is needed to create effective, non-intrusive support.
