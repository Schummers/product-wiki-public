# Storytelling in Design: Chapter 10. Applying Main Plots and Subplots to User Journeys and Flows

## Summary

This chapter explores how concepts from traditional storytelling—specifically main plots and subplots—can inform the design of realistic user journeys in products and services. Rather than designing only for ideal, linear user paths, Dahlström argues that product design should embrace the complexity of how users actually interact with products by mapping main journeys alongside the alternative, unhappy, and branched journeys that inevitably occur.

## Key Takeaways

- **Complexity in user journeys** — User journeys should reflect the messy, non-linear reality of how people actually use products: searching wide and far, shifting focus, moving between online and offline contexts. Abstracting to the ideal can miss critical design requirements.
- **Definition of subplots in product design** — Subplots are minor journeys that branch off from the main plot, resulting from users encountering problems, getting distracted, or making deliberate decisions. Cambridge Dictionary defines them as "a part of the story of a book or play that develops separately from the main story." In product design, they are often called edge cases, alternative paths, non-happy paths, or non-ideal paths; examples include forgotten password flows and shopping cart abandonment.
- **Types of subplots** — Traditional storytelling distinguishes mirroring, contrasting and complicating subplots (a typology Dahlström takes from Jordan McCollum). She proposes three types for product design: alternative journeys, which resemble mirroring subplots (different routes to the same destination, like entering through search versus social), unhappy journeys (experiences that don't go as the user intended, from minor frustrations to major failures), and branched journeys (decision tree structures in interactive experiences like chatbots, voice interfaces, and booking apps).
- **Techniques for structuring subplots** — *Writer's Digest* suggests seven ways to come up with a subplot; Dahlström retains the three with some applicability in product design. The isolated chunk (independent subplot not directly connected to main plot, exemplified in *Adventures of Huckleberry Finn*), the parallel line (subplot woven alongside the main plot with equal emphasis, as in Fredrick Forsyth's *The Day of the Jackal*), and the in-and-out (subplot involving different characters appearing and disappearing throughout the experience, as Harper Lee demonstrates in *To Kill a Mockingbird*).
- **Subplots must connect to the main plot** — Just as in traditional storytelling, every subplot in product design should have a connection to and impact on the main experience. If a subplot doesn't affect the main plot, it shouldn't be included in the design.
- **Visualization through storymaps** — Storymaps from traditional storytelling (the chapter's example is Gabriela Pereira's storymap of *The Hunger Games*, DIY MFA) commonly capture an overview of all the subplots, where the subplots and the main plot intersect, and what characters are involved in which subplot.

## Quotes

> Complex is, after all, an accurate description of the context in which our products will be used, and that complexity can be presented in multiple ways that are easy to understand.

> Just as the main plot should have acts and a clearly defined plot, all subplots should follow a narrative and have all the same elements as the main plot (e.g., an inciting incident and a climax).

> In traditional storytelling, each subplot should impact the main plot, or that subplot doesn't have a place in that story. In product design, the same is true: all alternate paths, whether happy or unhappy, should have a connection to the main experience.

## Concepts

- [[Subplot]] — the core framework Dahlström applies from storytelling; product design needs to map alternative journeys, unhappy journeys, and branched journeys as subplots that branch from and connect back to the main plot.
- [[Customer Journey]] — the chapter reframes user journeys as layered narratives, requiring design for ideal, alternative, and unhappy paths in parallel, not just the main happy path.
- [[Narrative Structure]] — Dahlström applies the main plot / subplot relation to user journeys: a subplot should have acts and carry the same narrative elements as the main plot (an inciting incident, a climax), and should impact the main plot, otherwise it does not belong in the story.
- [[User Flow]] — subplots map the alternative and edge case flows users take when things don't go as planned, such as forgotten passwords and error recovery paths.
