# Direct Manipulation: Definition

## Summary

Direct manipulation is an interaction style in which users act on displayed objects of interest using physical, incremental, and reversible actions whose effects are immediately visible on the screen. Examples include pinching to zoom into an image on a mobile phone or dragging a file from one folder to another. Coined by Ben Shneiderman in the early 1980s to contrast with command-line interfaces, direct manipulation combines menu-based interaction with physical actions like dragging and dropping. Key characteristics include continuous representation of objects, physical actions instead of complex syntax, continuous feedback, and rapid learning. However, direct manipulation has disadvantages: it only works with visible objects, can lead to repetitive strain injury, may provide no feedback when actions are not available, and can be slow for experts performing repetitive tasks. Despite downsides, direct manipulation enhances user empowerment and has proven effective for interfaces aimed at broad audiences with graphical components.

## Key Takeaways

- **Definition and characteristics** — Direct manipulation uses physical, visible, reversible actions; users see objects, perform actions, and immediately see results.
- **Advantages over command-line** — Direct manipulation requires recognition instead of recall; users can see available actions without remembering complex syntax.
- **Rapid learning** — Because objects and actions are visually represented, users can recognize what they can do; learning required is less substantial than with command-line interfaces.
- **Disadvantages of direct manipulation** — Only visible objects can be acted upon; physical actions require more effort and can cause RSI; some actions fail with no feedback; experts prefer keyboard shortcuts for repetitive tasks.
- **Accessibility challenges** — Direct-manipulation UIs can fail visually impaired or motor-impaired users; workarounds exist but can be difficult to implement.

## Quotes

> Direct manipulation (DM) is an interaction style in which users act on displayed objects of interest using physical, incremental, and reversible actions whose effects are immediately visible on the screen.

> Direct manipulation is one of the central concepts of graphical user interfaces (GUIs) and is sometimes equated with "what you see is what you get" (WYSIWYG). These interfaces combine menu-based interaction with physical actions such as dragging and dropping in order to help the user use the interface with minimal learning.

> It's hard to imagine modern interfaces without direct manipulation. Almost any interface that is aimed at a broad audience and has a graphical component is based on DM.

## Concepts

- [[Interaction Design]] — Direct manipulation is a core interaction paradigm that supports user empowerment and control through physical, visible actions, reducing the gulf between user intentions and system actions.
- [[User Interface]] — Modern UIs are built on direct-manipulation principles; interfaces succeed by making objects and available actions visible.
- [[Usability]] — Direct manipulation supports usability through immediate feedback, reduced learning requirements, and recognition-based action selection.
- [[Feedback Design]] — Continuous visibility of objects and immediate feedback on actions are essential characteristics that make direct manipulation effective.
