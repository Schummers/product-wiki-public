# User-Experience Quiz: 2019 UX Year in Review

## Summary

This quiz compiles ten questions covering major UX topics published by Nielsen Norman Group in 2019, testing knowledge across touch target dimensions, mobile microsessions, eye-scanning patterns, formative evaluation, UI modes, cognitive maps, information foraging, treemaps, thematic analysis, and UI copy. The quiz serves as a self-assessment tool for UX practitioners and includes scoring guidance: 10 points suggests job-ready expertise; 8-9 indicates UX expert level; 6-7 shows competent knowledge; 1-5 needs study; 0 suggests lack of UX engagement.

## Key Takeaways

- **Recommended touch target dimensions** — article references recommend specific dimensions for mobile touch targets (answer not revealed in abstract).
- **Mobile microsessions characteristics** — includes tasks like reading notifications or checking calendar; excludes longer tasks like reading reviews and purchasing.
- **Layer-cake eye-scanning pattern** — eye fixations placed on specific words and chunks spread throughout page, not headings or all words.
- **Formative evaluation definition** — qualitative usability testing on prototypes to determine what design changes are needed; different from summative comparative or baseline testing.
- **UI mode example** — pressing CAPS LOCK to type in capitals exemplifies a UI mode; distinct from keyboard shortcuts, view toggles, or multiple action methods.
- **Cognitive map types** — generic term for any visual representation of mental models; specific types include tree representations and graph representations with nodes and labeled edges.
- **Information foraging definition** — theory of how people navigate web to satisfy information needs; distinct from attention patterns, content design methods, or information architecture methods.
- **Treemap visualization** — visualization method for any hierarchical data; distinct from IA evaluation, site IA representation, or map organization tools.
- **Thematic analysis application** — method for analyzing qualitative data from interviews; not used for quantitative data, analytics, or biometric data.
- **UI copy definition** — includes all labels for commands, link text, and short content for headlines, subject lines, page titles, tooltips.
