# A/B Testing 101

## Summary

This article explains A/B testing as a quantitative research method for comparing design variations with live users to determine which performs better against predetermined business metrics. It outlines a four-step process: start with a hypothesis, define the changes to make, choose outcome metrics, and determine the test timeframe. The article addresses when A/B testing is appropriate (high-traffic products, single design element changes, clear success metrics) and common mistakes (missing goals, stopping too early, testing without hypothesis, focusing on single metrics).

## Key Takeaways

- **A/B testing measures user behavior change, not why it changed** — A/B tests excel at determining which design variation users prefer but provide no insight into reasons behind behavior changes; combine with qualitative research for complete understanding.
- **Start with hypothesis from user research** — one in seven A/B tests is a winning test; success rates improve dramatically when hypothesis is based on qualitative research findings rather than untested assumptions.
- **Test requires sufficient sample size and duration** — use calculators to determine required sample size based on baseline metric, minimum detectable effect, and statistical significance threshold; run tests at least 1-2 weeks to account for behavioral fluctuations.
- **Track guardrail metrics alongside primary metrics** — testing only one metric risks capturing design changes that help one metric while harming others (like deceptive patterns increasing conversions while decreasing retention).
- **A/B testing is unsuited for low-traffic products and multiple changes** — pages needing thousands of users to reach significance and tests of multiple elements simultaneously require alternatives like multivariate testing.

## Quotes

> A/B testing is a quantitative research method that tests two or more design variations with a live audience to determine which variation performs best according to a predetermined set of business-success metrics.
