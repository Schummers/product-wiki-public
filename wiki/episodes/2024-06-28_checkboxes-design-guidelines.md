# Checkboxes: Design Guidelines

## Summary

Checkboxes are UI elements allowing users to select zero or more items from a list, distinguishing them from radio buttons (exactly one selection). The article covers three checkbox types (standalone, list, nested), explains when each is appropriate, provides comparison with alternative input fields, and offers detailed usability guidelines covering visual conventions, label selectability, logical ordering, and clear state messaging. Proper checkbox design prevents errors and confusion while accommodating different user needs for selection flexibility.

## Key Takeaways

- **Three checkbox types serve different needs** — standalone checkboxes appear alone (e.g., terms agreement), list checkboxes allow multiple independent selections (e.g., pizza toppings), and nested checkboxes use parent-child relationships with select-all functionality.
- **Use standard visual conventions** — checkboxes should be square (optionally rounded), never circular; a checkmark indicates selection. Circles are easily confused with radio buttons.
- **Make labels clickable** — extend the click target beyond the small checkbox box; users should be able to click the label to toggle selection.
- **Use positively worded labels** — avoid negatively worded statements like "Do not send me updates" which create confusing double negatives when unchecked.
- **List items vertically** — horizontal checkbox lists are harder to scan and can misalign labels with checkboxes; vertical is always better.
- **Clarify minimum/maximum selections** — if users must select at least one or no more than three items, state this explicitly and provide real-time feedback.
- **Distinguish from radio buttons and other inputs** — different selection needs require different controls; using the right control type prevents user confusion.

## Quotes

> "A checkbox is a UI element that allows users to select between two states: checked and unchecked."

> "Nested checkboxes use a parent checkbox followed by a sublist of indented child checkboxes."

> "Double negatives are harder to understand."
