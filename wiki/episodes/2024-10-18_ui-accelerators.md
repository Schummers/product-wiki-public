# Accelerators Maximize Efficiency in User Interfaces

## Summary

Aurora Harley and Rachel Krause explain how accelerators (shortcuts) in user interfaces allow expert users to work more efficiently while maintaining learnability for novice users. Accelerators are defined as UI features that speed up interactions by providing alternate methods for accomplishing tasks, including keyboard shortcuts, gestures, and voice commands. The article addresses the critical tension in interface design: keeping interfaces simple for new users while providing power features for experienced users. Proper accelerator design involves gradual revelation, clear discoverability strategies, and a focus on genuinely frequent actions rather than every possible task.

## Key Takeaways

- **Accelerators help expert users bypass the efficiency plateau** — once users fully learn an interface, further repetition provides little speedup; accelerators push users past that plateau by enabling faster task completion.
- **Accelerators should be discovered gradually** — novice users should not be overwhelmed by shortcuts; instead, accelerators should be revealed as users become more familiar with core functionality through hints, tooltips, and inline display.
- **Accelerators must be additional, never required** — shortcuts are enhancements for power users; all tasks must remain completable through the standard interface, or accelerators create usability problems.
- **Focus on high-frequency, core actions** — prioritize accelerators for tasks users perform repeatedly, where speed gains actually matter; avoid creating shortcuts for rarely-used functions.
- **Consistency across platforms reduces cognitive load** — when the same shortcut works the same way across web, mobile, and desktop versions, users transfer learning between platforms and adopt shortcuts faster.
- **Always provide recovery options** — accelerators that trigger destructive actions should offer undo, confirmation dialogs, or snackbar confirmations so users can recover from accidental activation.
- **Display shortcuts inline and contextually** — showing keyboard shortcuts right-aligned in menus, displaying them on hover, or using just-in-time hints makes them discoverable without requiring users to search documentation.

## Quotes

> An accelerator is a UI feature that speeds up an interaction or process.

> Because accelerators are enhancements to the interface, **discovering them should not be critical****to learning and using the interface**. In fact, you shouldn't aim to expose new users to every accelerator, as that would be overwhelming and not helpful.

> Repeat users who are already familiar with an interface want to be efficient, whereas novice users need the interface to be as explicit as possible so they can find their way around. Accelerators help balance the needs of both types of users and enhance an interface by giving them control over completing an action. This is what makes a system highly flexible — and ultimately widely usable.

## Concepts

- [[UI Accelerators]] — interface features that provide alternate, faster methods for expert users to accomplish common tasks, while remaining invisible and optional for novice users.
- [[Keyboard Shortcuts]] — accelerators that use keyboard key combinations to trigger actions more quickly than using mouse navigation and menus.
- [[User Efficiency]] — the speed and ease with which users can accomplish their goals in a system, particularly important for power users and repeated task scenarios.
