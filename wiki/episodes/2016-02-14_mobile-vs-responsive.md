# Mobile Websites: Mobile-Dedicated, Responsive, Adaptive, or Desktop Site?

## Summary

Four approaches to serving mobile users exist: mobile-dedicated sites (separate URL, mobile-optimized), responsive design (same content, dynamically adjusted layout), adaptive design (server detects device capabilities and serves appropriate content), and desktop sites (not recommended). Each approach has trade-offs. Responsive design offers content parity and a single codebase but can be slower and more expensive. Mobile-dedicated sites are often faster and simpler but require separate maintenance. Adaptive design solves performance issues by serving lightweight versions to less capable devices. Users benefit more from mobile-optimized experiences than they expect to.

## Key Takeaways

- **Responsive design provides content parity** — the same content and (mostly) the same functionality are available across all screen sizes with a single codebase, reducing maintenance burden compared to mobile-dedicated sites.
- **Responsive sites tend to be slower** — because the same content is delivered to all devices, responsive pages often load more slowly than optimized mobile-dedicated versions.
- **Adaptive design solves performance with content negotiation** — the server detects device capabilities and sends only what the device can handle, providing performance benefits while maintaining some content parity.
- **Mobile-dedicated sites trade breadth for depth** — they often omit complex features and content, but this simplification can actually improve usability for mobile tasks.
- **Don't break web conventions just because you have flexibility** — responsive design requires deliberate responsive thinking; simply rewrapping desktop content on small screens does not guarantee usable mobile interfaces.
- **Users prefer mobile-optimized sites in practice** — despite saying they prefer full desktop sites, users are actually more efficient and successful when using mobile-optimized experiences.

## Quotes

> The same responsive site can work well on a range of devices and screen sizes, from smartphones to tablets to desktops.

> Responsive sites tend to be more expensive to develop.

> You should not listen to what users say, but rather look at what they do. When people use mobile-optimized sites on their mobile devices, they typically are more efficient and more successful.
