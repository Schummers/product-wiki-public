# Prompt Suggestions

## Summary

Prompt suggestions are system-generated hints that guide users in forming queries for AI tools, addressing the "blank page problem" when users first interact with AI systems. The article distinguishes prompt suggestions from traditional and enriched search suggestions, identifying their role in supporting discoverability and learnability. Three types exist: use-case prompt suggestions (examples showing what the system can do), prompt autocomplete (continuations helping efficiency), and followup questions (context-aware suggestions building on previous interactions). When designed thoughtfully, prompt suggestions reduce cognitive load, interaction cost, encourage exploration, and improve task efficiency.

## Key Takeaways

- **Prompt suggestions solve the blank-page problem for AI tool onboarding** — new users face uncertainty about how to interact with open-text AI systems; suggestions guide them toward effective prompting by demonstrating capabilities and reducing mental effort to get started.
- **Three distinct types serve different purposes** — use-case suggestions (supporting learnability and creativity) showcase system capabilities through example prompts; prompt autocomplete (increasing efficiency) completes partial prompts following best practices; followup questions (increasing engagement) contextualize suggestions to ongoing conversations.
- **Prompt suggestions are not search suggestions** — unlike traditional search suggestions (which predict sentence endings as users type), prompt suggestions often aim to inspire interaction and guide capability discovery rather than merely complete user input.
- **Followup questions are most relevant and useful** — currently the most effective type because they're tailored to specific user needs and interests established by previous interactions rather than generic demonstrations.
- **Well-designed suggestions significantly improve UX** — reduce cognitive load and interaction cost by offering ideas or phrasing; encourage exploration of capabilities users might not have known about; help users formulate better prompts when uncertain how to begin.
