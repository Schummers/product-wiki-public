# The Lawn Mower Eyetracking Pattern for Scanning Comparison Tables

## Summary

The lawn mower pattern is a predictable eye-tracking behavior where users scanning comparison tables move left-to-right, then drop down and right-to-left, continuing row by row like a lawn mower sweeping across a field. This pattern emerges when users actively compare features of multiple products or services in a table-based layout, after an initial appraisal phase. The pattern represents an efficient scanning strategy that minimizes eye movement, but poor table design disrupts it, increasing cognitive load and frustration.

## Key Takeaways

- **Lawn mower pattern occurs during active comparison** — users adopt this row-by-row, back-and-forth scanning specifically when comparing features of adjacent products or services in a comparison table.
- **Initial appraisal precedes the pattern** — before entering the lawn mower pattern, users quickly scan column and row labels to understand the table's structure.
- **Length disrupts the pattern** — when tables are very long, users lose track of column assignments and must repeatedly return to the top to verify which product is in which column, breaking the pattern and adding cognitive strain.
- **Unexplained jargon causes hesitation** — users pause and fixate when encountering unfamiliar technical terms, creating dense fixation clusters that interrupt their scanning rhythm.
- **Design should support the pattern** — effective comparison table design uses fixed headers, narrower navigation, self-explanatory cells, grouped yes/no features, minimal repetition, clear terminology, and avoids placeholder content.
