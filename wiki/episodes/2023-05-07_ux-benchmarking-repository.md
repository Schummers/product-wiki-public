# Documenting a UX-Benchmarking Study

## Summary

UX benchmarking measures and compares how different product versions perform on key usability metrics. To accurately compare versions over time, researchers must maintain absolute consistency in study methodology, tasks, metrics, and participant recruitment across all iterations. A comprehensive benchmark-study repository documents the protocol, tasks, screener, metric definitions, and raw data so future iterations can be replicated precisely. Without this consistency, observed improvements may reflect differences in how the study was conducted rather than actual design improvements.

## Key Takeaways

- **Consistency is essential** — Any difference in methodology, study type, tool, task wording, or metrics between benchmark iterations makes valid comparison impossible and can invalidate conclusions.
- **Document methodology minutely** — Specify study type, platform, think-aloud protocol, and participant instructions so researchers can replicate everything across years and product versions.
- **Keep tasks stable** — Top tasks should remain the same across iterations; if tasks change, comparisons become unsound, though adding tasks may be acceptable.
- **Define metrics precisely** — Even seemingly obvious metrics like success need clear definition; specify whether you measure only completions or all attempts, how rating questions are scored.
- **Save raw data, not summaries** — The original data spreadsheet is essential for future statistical analysis, revising analyses with new methods, and investigating coding errors.
- **Plan for future changes carefully** — Studies can change completely if needed, but any change to task wording or metric definition will break comparisons with prior versions.

## Quotes

> To soundly compare the results from the two studies, the company needs to compare apples to apples. In other words, the studies need to have the same methodology and collect the same metrics.

> Any company that considers a benchmarking practice should first define the benchmark study in minute detail and document it so that subsequent versions of the same design could be evaluated using the exact same methodology and metrics.
