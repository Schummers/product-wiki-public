# Homepage Links Remain a Necessity

## Summary

Direct one-click links to the homepage are essential for websites. Users need them when disoriented, when they have gone too deep into a site, or when starting a new task. Many users bypass the homepage through search engine landing, so homepage links provide a new starting point. Two types of homepage links exist: implicit (via logo) and explicit (labeled Home). While clickable logos are a strong convention, many users still don't understand this behavior. Effective designs use both types, placing logos in the top-left corner and including Home links in navigation or breadcrumbs. Include a visible Home link only on interior pages, not the homepage itself.

## Key Takeaways

- **Provide both implicit and explicit links** — Use both a clickable logo (implicit) and a Home link label (explicit). Many users know to click logos; others expect to find an explicit Home link. Together they ensure broad coverage of user expectations.

- **Left-aligned logos work significantly better** — Users are 6 times more likely to find the homepage link in one click when logos are left-aligned than centered or right-aligned. This expectation is so strong that non-standard placement damages usability.

- **Make logos visually distinct** — If logos look like navigation text or page headings, they blend in and become harder to locate. Apply visual styling that makes logos stand out from other text elements.

- **Include Home in breadcrumbs** — When using breadcrumb navigation, start with the Home link as the highest level. This provides accessible, prominent access to the homepage without duplication.

- **Don't show Home as an active link on the homepage** — It's confusing to show an active/clickable link to the current page. On the homepage, either show Home in a selected visual state or omit the link entirely.
