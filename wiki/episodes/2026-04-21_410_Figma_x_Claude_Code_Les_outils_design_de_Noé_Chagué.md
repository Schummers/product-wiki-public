# #410 Figma x Claude Code : Les outils design de Noé Chagué

## 📝 Résumé & Contexte
L'épisode reçoit Noé Chagué, Design System Engineer chez Finary, qui présente Bridge, un outil open-source connectant un design system Figma au code de production via Claude Code. L'échange explore comment l'automatisation de l'exécution permet aux product managers de prototyper des interfaces conformes. Cela pousse naturellement les designers à déléguer les tâches répétitives pour se recentrer sur la créativité et l'architecture des systèmes.

## 💡 Points Clés & Enseignements
* **Bridge, un pont entre Figma et Claude Code** : Bridge est une base de connaissances open-source qui permet à Claude Code de comprendre un design system Figma. Il génère ensuite directement de l'interface dans Figma à partir d'une simple spécification textuelle.
* **Autonomie des Product Managers** : L'outil permet à des profils non-designers de concevoir des écrans entièrement conformes au design system. Le designer intervient alors davantage comme un relecteur que comme un simple exécutant.
* **Amélioration continue via le workflow Learn** : Le processus de Bridge intègre une action d'apprentissage itérative. Lorsque le designer corrige manuellement le résultat généré, l'IA analyse cette différence pour éviter de refaire les mêmes erreurs.
* **L'avenir des compétences du designer** : Avec l'automatisation de l'exécution, l'avenir du design réside dans deux extrêmes : la créativité pure pour apporter une différenciation visuelle, et l'architecture produit pour penser les flux complexes.

## 💬 Citations Marquantes
> "Tout l'aspect exécutif, je le délègue à Breach et moi, je me concentre plus sur des sujets créatifs."
> "L'exécution, encore une fois, à Claude, le fera beaucoup mieux que moi et même qu'un développeur. Et donc moi, tout ce qui m'intéresse, c'est tout cet aspect architecture, flow."

## 🔗 Concepts Abordés
* [[Design System]] : L'épisode montre comment utiliser les composants et tokens d'un design system comme instructions de base pour l'IA afin de générer des maquettes conformes.
* [[Model Context Protocol]] : Figma a développé un MCP officiel qui permet aux modèles comme Claude Code d'accéder qualitativement aux données du design.
* [[Open Source]] : L'outil Bridge est publié en open source pour que chaque entreprise puisse l'adapter à ses propres processus et méthodes de travail dans Figma.
