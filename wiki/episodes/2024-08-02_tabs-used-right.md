# Tabs, Used Right

## Summary

This article provides updated best practices for tabs, a fundamental interface control for organizing and presenting content. It distinguishes between in-page tabs (which keep users on one page while switching content views) and navigation tabs (which navigate to different pages), explains when tabs are appropriate versus alternatives like accordions, and details visual design practices, content arrangement, and label strategies that ensure tabs work effectively without introducing usability problems.

## Key Takeaways

- **Tabs work best with few options and clear groupings** — tabs minimize cognitive load by chunking content, but work best when there are few tabs and content within each tab is related.
- **In-page and navigation tabs must not mix** — mixing tab types disorients users; in-page tabs should keep users in place with similar content, while navigation tabs should navigate with dissimilar content.
- **Selection indicators require multiple cues** — using at least two indicators like underlines combined with font styling makes the selected tab clear and distinguishes it from unselected options.
- **Tab labels need information scent** — concise labels using plain language help users predict content before clicking, especially important since unselected tabs hide their content.
- **Tabs versus accordions trade off** — on desktop, tabs are preferable for organizing lengthy content and complex layouts, while accordions work better on mobile and for short content like FAQs.

## Quotes

> Tabs allow users to selectively view a single panel of content from among a list of options.

> Tabs minimize cognitive load by chunking content into scannable pieces instead of showing it all at once.
