# Proximity Principle in Visual Design

## Summary

The proximity principle is a foundational Gestalt grouping principle asserting that items placed close together are perceived as related and belonging to the same group. This principle is critical in UI design, where correctly interpreting which elements are related is essential for successful user interaction. The practice of placing related elements near each other and separating unrelated elements using whitespace is nearly universal in interface design and helps users quickly identify and focus on relevant UI elements.

## Key Takeaways

- **Principle definition** — Items close together are likely perceived as part of the same group, sharing similar functionality or traits. Proximity can overpower other visual cues like color or shape.
- **Whitespace as separator** — Using varying amounts of whitespace to either unite or separate elements is key to communicating meaningful groupings. Extra whitespace signals that elements belong to different groups and have different functionalities.
- **Form design application** — Grouping related form fields together makes forms easier to scan and less daunting to complete. A single form with 12 fields appears more taxing than the same fields broken into three meaningful groups.
- **Responsive design challenges** — Proximity relationships may change as layouts adapt to different screen sizes. Columns displayed side-by-side on desktop may stack vertically on mobile, destroying grouping relationships and causing users to miss related information.
- **Overlapping groupings** — Grouping unrelated elements together can camouflage them from users, especially when following a task. Users may only look at one item in a perceived grouping and make judgments about all items in that group based on that single item.
- **Task-focused scanning** — Users selectively attend to certain screen areas while completing tasks and miss things "in plain sight" when they are outside the focal area, a behavior described as tunnel vision.

## Quotes

> Items close together are likely to be perceived as part of the same group — sharing similar functionality or traits.

> Placing related elements close together and separating unrelated elements can be seen almost everywhere in UI design.

> Users selectively attend to certain areas of the screen as they complete their task and miss things "in plain sight" because they are outside this focal area.

## Concepts

- [[Gestalt Principles]] — Proximity is one of the original Gestalt grouping principles (along with similarity and closure) and remains essential for creating usable interfaces that help users understand relationships between elements.
- [[Visual Grouping]] — Proximity is a primary mechanism for signifying relationships between UI elements, allowing designers to communicate which elements are related and which have different functionalities.
- [[Whitespace]] — Strategic use of whitespace is key to applying the proximity principle, creating visual separation between groups of elements and making groupings clear to users.
