# Working Memory and External Memory

## Summary

Working memory functions as a limited-capacity buffer where the mind stores information relevant to the current task. When interfaces require too much working memory, users forget information needed for task completion and make mistakes. Designers can reduce cognitive load by providing external memory tools that let users offload information rather than keep it in mind. Examples include comparison tables, shopping carts, note-taking, and page parking. Understanding working-memory capacity variation across users helps designers avoid assuming their own large capacity applies universally.

## Key Takeaways

- **Working memory limitations** — human working memory has limited capacity; exceeding it requires users to dump information to make space, leading to errors or longer task times.
- **Chunking and capacity** — working memory can hold approximately 7 chunks of information for brief periods; the exact capacity varies by individual, education, and age.
- **Developer bias** — programmers often have larger working-memory capacity than typical users due to self-selection; interface features that seem easy to developers may overload most users.
- **External memory solutions** — comparison tables, shopping carts, open tabs, and note-taking features act as virtual scratchpads allowing users to externalize information and reduce cognitive burden.
- **Mobile penalty** — smaller mobile screens reduce the amount of external memory visible at once; users must scroll to access previous content they could see on larger screens, increasing working-memory demands.

## Quotes

> The user interface requires them to keep in their working memory more than what their brains can hold.

> Human working memory can be conceptualized as a buffer or scratchpad in which the mind deposits information relevant to the current task.

> Make sure that users can easily access all the information they need for a task, without having to commit it to working memory.

## Concepts

- [[Cognitive Load]] — understanding how interface design increases or decreases the burden on working memory and overall cognitive effort.
- [[Cognitive Psychology]] — applying cognitive psychology findings about memory limitations to inform design decisions and interaction flows.
- [[Interaction Design]] — providing UI features like comparison tools and persistent storage that help users manage complex tasks within cognitive constraints.
