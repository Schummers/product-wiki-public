# Mobile Tables: Comparisons and Other Data Tables

## Summary

Displaying data tables on small mobile screens requires careful design to avoid overwhelming users with information they cannot see at once. The smaller the screen, the more critical design choices become. Before adapting a table for mobile, designers should first ensure it works well on desktop by including only meaningful data and attributes. Mobile-specific techniques include sticky headers and row labels, horizontal scrolling indicators, user-selectable data columns, accordions for grouped information, and the ability to filter data before display. In all cases, legibility without zooming and clear context are non-negotiable.

## Key Takeaways

- **Create a usable desktop table first** — before adapting for mobile, ensure the table contains only meaningful attributes and consistent content; mobile constraints may reveal improvements that benefit all users.
- **Columns must be legible without zooming** — the number of columns that fit depends on content complexity; wordy comparison tables may show only 2 columns, while numeric data can fit more.
- **Stick column headers in place** — when tables exceed one screen height vertically, users lose context without persistent headers showing what each column represents.
- **Indicate horizontal scrolling is available** — use cut-off elements or arrows at the edge to signal more data; dots are less effective at drawing attention than visual cuts or arrows.
- **Let users control what data they see** — provide filters to narrow data before viewing, toggles to show only relevant columns, or accordions to expand data categories on demand.

## Quotes

> The smaller the screen, the more likely that we'll get into trouble with any given dataset and will need to design carefully to minimize usability problems.

> You must first create a usable table for a large screen before translating it to a small one.

> Signposts such as locked headers orient users when they scroll through the data, and tools that narrow down content according to user-specified criteria allow them to view the data in a meaningful way.

## Concepts

- [[Responsive Design]] — adapting tables from desktop to mobile requires different techniques than simple scaling; sticky elements, user controls, and content prioritization are essential.
- [[Data Visualization]] — presenting structured data accessibly on small screens demands clear hierarchy, scent, and user control over what information is displayed.
- [[Mobile Design]] — mobile tables must accommodate smaller viewports, varied network speeds, and touch interaction; legibility and context are paramount.
