# Leverage AI for Mock Tables and Charts When Testing Prototypes

## Summary

This article explains how generative AI can accelerate prototype creation by generating realistic mock data for tables and charts. Since research participants scrutinize unfamiliar data looking for inconsistencies, prototypes need content fidelity. The article provides 14 practical tactics for generating mock tables (contextualization, volume definition, sorting, specifications, chart reference, participant contextualization, verification) and mock charts (describing narrative, eliminating clutter, emphasizing outliers, dimensions, SVG format, critical thinking, data provision). It addresses considerations for importing data into design tools and cautions about synthetic data in regulated industries.

## Key Takeaways

- **Content fidelity affects usability testing validity** — participants scrutinize unfamiliar data looking for outliers and inconsistencies; prototypes need realistic mock data so testing focuses on design, not data questions.
- **Context drives realistic data** — providing AI with business size, industry, geography, and product type makes generated data contextually appropriate; a boutique shoemaker dataset differs radically from a large corporation.
- **Volume definition prevents scaling errors** — specifying the size of the larger dataset (e.g., 2000 transactions total, showing 50) helps AI generate proportionally correct values for the displayed sample.
- **Specifications ensure plausible data** — defining uniqueness constraints, fixed values, formatting, plausible ranges, and value distributions produces authentic-looking data that supports testing tasks.
- **Verification prevents AI math errors** — requiring AI to show calculations, use coding tools for math, and verify results before finishing prevents hallucinated numbers that pass usability tests despite being mathematically wrong.

## Quotes

> Prototype testing is at the core user-centered design. But crafting realistic data for prototypes that you plan to test is time-consuming.

> Research in data sensemaking by Laura Koesten and colleagues found that when participants were given unfamiliar data, they spent more time looking for outliers and inconsistencies than when they worked with familiar data.
