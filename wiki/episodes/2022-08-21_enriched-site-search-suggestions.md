# Enriched Site-Search Suggestions: Rarely Used

## Summary

Despite prominence in search interfaces, enriched search suggestions (featured results, trending items, recently viewed products, category links) are utilized only 7 times out of 60 instances encountered in a usability study. The mismatch between implementation effort and actual usage stems from fundamental design problems: users in search mode are goal-focused and not interested in exploring, enriched suggestions often load too slowly to be useful, banner blindness causes users to ignore graphical content, and users interpret suggestions as promotional content rather than search results. Text autocomplete suggestions remain heavily used, but adding graphical elements and dynamic content typically reduces usability without adding value. Designers should focus on simple, fast text suggestions while limiting graphical and changing content that contributes to low signal-to-noise ratio and user frustration.

## Key Takeaways

- **Search mindset vs. explore mindset** — Users in search are goal-focused and want to find known items quickly, not explore; enriched suggestions that are irrelevant to the query feel like unwanted distractions rather than helpful shortcuts.
- **Slow loading defeats purpose** — Enriched results, particularly image-based ones, often load too slowly to be useful; by the time relevant images appear, users have already submitted their query and moved forward, making the suggestions useless.
- **Banner blindness obscures results** — Users fixate on the search box and ignore graphical content in enriched results; even exact product matches are overlooked when displayed as images in the enriched container.
- **Promotional misinterpretation** — Users without prior knowledge interpret enriched suggestions as ads or upsell attempts rather than search results; unlabeled suggestions especially trigger this perception and cause users to ignore them.
- **Keep text suggestions simple** — Users heavily utilize basic text autocomplete suggestions; these should be maintained and optimized even when adding enriched suggestions.
- **Avoid shifting content types** — Inconsistent placement and changing content categories in the enriched container create confusion and increase perceived noise; dedicated spaces for each content type improve clarity.

## Quotes

> Enriched search suggestions often blend text- and image-based formats and link directly to different types of content. Some enriched search suggestions are based off the user's query (e.g., related product or category pages) and others — such as featured items — are not, combining search functionality and promotional efforts.

> When users choose to interact with a site's search function, they typically already have a preformulated search query in mind. They use the search feature to bypass navigation and get to that item as quickly as possible.

> Do not eliminate simple text autosuggestions. Users heavily utilize these basic site-search suggestions even when enriched search suggestions are present.

## Concepts

- [[Search]] — Search is a critical path to task completion and essential for conversions; text autocomplete suggestions are heavily used and effective, but enriched graphical suggestions add little value and often create usability problems if not implemented carefully.
- [[Banner Blindness]] — Users direct attention to primary task-relevant elements like search bars and ignore secondary graphical content; this selective attention explains why enriched image suggestions go unnoticed.
- [[Interaction Cost]] — Search is brief and transactional; even small delays in content loading or distractions from the search goal can cause users to lose interest or abandon suggestions.
- [[E-Commerce]] — Shopping search requires fast text suggestions; enriched results intended to increase browsing or upsell often backfire when users are in quick-purchase mode.
