# Visual Design: Glossary

## Summary

A comprehensive glossary of visual design terms organized alphabetically, covering foundational principles (Gestalt principles, visual hierarchy, balance), practical techniques (color palettes, contrast, scale), and specific UI concepts (flat design, responsive design, wireframes). The glossary serves as a reference tool for designers to communicate precisely about visual design decisions and understand how conceptual principles translate into specific interface choices.

## Key Takeaways

- **Gestalt principles explain visual grouping** — principles like proximity, similarity, closure, and continuation describe how humans naturally organize visual elements into meaningful groups.
- **Visual hierarchy guides user attention** — designers use color, contrast, scale, and grouping to direct users toward content in order of importance.
- **Contrast and brightness affect readability** — text and graphical elements must maintain sufficient contrast against their backgrounds to ensure legibility and accessibility.
- **Consistency provides predictability** — internal consistency within a product and external consistency with design conventions reduce cognitive load and improve usability.
- **Whitespace is a design element** — empty space between elements is not wasted space but a tool for creating balance, emphasis, and scannability.
- **Responsive design adapts to context** — interfaces must adapt to different screen sizes and devices to provide optimal user experience across platforms.
