# Alt Text: What to Write

## Summary

This article provides practical guidance on writing effective alt text when images require it. The article categorizes images into three types — decorative, functional, and informative — and explains what alt text should communicate for each type. When alt text is needed, it should be concise, frontload important information, avoid jargon, and focus on the image's purpose in the context of the page rather than describing what the image looks like. The article also covers simple and complex informative images, emphasizing that AI cannot yet reliably write alt text without human oversight.

## Key Takeaways

- **Write alt text only when needed** — If an image is essential for understanding page content or completing tasks, it needs alt text; decorative images should have empty alt attributes.
- **Keep alt text short and purposeful** — Alt text should be approximately 150 characters or less, frontload the most important information, and communicate what users need to know rather than describing visual appearance.
- **Consider context** — The context of an image and the author's intention for including it determine what the alt text should say; the same image needs different alt text in different contexts.
- **Three types of images require different approaches** — Decorative images need empty alt attributes, functional images should describe the action they afford, and informative images should highlight their unique value without redundantly restating page copy.
- **Complex informative images need structured descriptions** — For complex images like charts or diagrams, consider altering page copy to include the information as a table or list, or provide a long description.
- **AI needs human oversight** — Generative AI tools struggle to understand image context and author intent; treat AI-generated alt text as a first draft requiring verification and editing.

## Quotes

> **If an image is essential for a task or for understanding page content, it needs alt text.**

> The context of an image and the author's intention for including it determine what the alt text should say, which is why the best alt text is created with input from those who write the content and choose the images.

> Use AI to refine alt text rather than relying on AI to write it from scratch — particularly when using LLM chatbots like ChatGPT.
