# Remote Moderated Usability Tests: How to Do Them

## Summary

Remote moderated usability testing offers significant advantages over in-person studies, including lower costs, reduced time consumption, and greater convenience for participants. However, it requires substantial advance preparation, particularly in tool selection and setup. This article provides seven systematic steps for conducting successful remote moderated sessions: choosing appropriate screen-sharing tools, planning task administration, scheduling technology-practice sessions, sending reminders, inviting observers at the right time, running proper session scripts, and ending sessions with team debriefs. Key considerations include handling mobile testing challenges, managing webcam video, allowing flexible task delivery methods, and preparing for technical failures.

## Key Takeaways

- **Tool selection requires careful evaluation** — consider installation requirements, operating system and browser compatibility, and whether the tool supports mobile testing, as mobile tools often have stability issues.
- **Task administration needs flexibility** — offer three options (PDF documents, chat delivery, or moderator reading) while ensuring participants read tasks aloud themselves to confirm comprehension and prevent looking ahead.
- **Technology practice sessions prevent failures** — scheduling a 15-minute online meeting the day before testing helps participants install software, troubleshoot issues, and practice screen sharing without showing the actual test prototype.
- **Webcam video improves communication** — sharing participant and facilitator faces enhances communication during sessions, provided the system and connection can handle it.
- **Add extra time to accommodate problems** — even with successful practice sessions, unexpected technical issues often arise (like overnight system updates), so building buffer time prevents ruined sessions.
- **Observer logistics require clear communication** — establish rules for muting observers, managing chat privacy, and determining when observers should join relative to participant arrival.

## Quotes

> Perhaps the biggest downside to remote moderated usability testing is that it can require lots of advance preparation, particularly in setting up the tool you use.

> It's important to emphasize to participants that they need to be in a quiet, private location with a good internet connection.

> Accept that things will go wrong and have a backup plan. Software gets updated at the last minute, firewalls interfere, apps have bugs.
