# Designing AI Agents: 4 Lessons from China's Qwen Agent

## Summary

Qwen, an AI chatbot built by Alibaba, tested early AI-agent features with Chinese users for ordering food, booking travel, and purchasing entertainment. Although the underlying capability was strong, usability issues created confusion, uncertainty, and friction. Participants struggled with unfamiliar interaction patterns, expected familiar UI conventions, had privacy concerns about data access, and felt misled by hidden pricing. The findings reveal that capability alone is insufficient for AI agents to gain adoption; users must understand, guide, and trust the system. Chinese tech platforms' structural advantage—years of bundled services and behavioral data—means agents can anticipate requests in ways Western counterparts cannot.

## Key Takeaways

- **Support Discoverability Through Redundancy** — Mental models of chatbots favor answering questions over completing transactions; redundant entry points (text prompts and visual menus) help users discover agent capabilities, though prefilled prompts for broad categories can backfire if they default to the wrong choice.
- **Use Familiar Patterns** — Users gain confidence when agent interfaces mirror established UI conventions like delivery apps; however, familiar patterns must still fit context, as carousels showing one option at a time underestimate available choices.
- **Handle Personal Data Carefully** — Users don't always understand how AI agents access or use their data; displaying a full address before item selection creates false impressions of data leakage; surface only minimum data per step and explain how it's used.
- **Prioritize Transparency to Protect Autonomy** — Users want efficiency without losing control; missing information about pricing, fees, minimum orders, or flight baggage allowances causes abandonment; agents that inform users retain long-term trust.
- **Structural Advantage for Bundled Platforms** — Platforms like Alibaba gain competitive advantage in building agents because they already own delivery, payments, and behavior data; agents can anticipate requests and default to user preferences, keeping users inside the ecosystem.

## Concepts

- [[AI Agent]] — Successful agent design requires supporting discoverability through redundant entry points, using familiar interaction patterns, and maintaining user control through transparency about data, pricing, and limitations.
- [[Mental Model]] — Users approach agents with mental models shaped by prior experience; agents must either align with existing models or explicitly teach new paradigms; mental-model mismatches cause confusion and abandonment.
- [[Privacy]] — Users form privacy perceptions based on what they see displayed; agents must explain data access clearly and surface only minimum required information at each step to prevent false impressions of data leakage.
