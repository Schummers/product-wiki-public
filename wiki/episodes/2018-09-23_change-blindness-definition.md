# Change Blindness in UX: Definition

## Summary

Change blindness refers to people's tendency to overlook changes in a scene when attention is focused elsewhere. This fundamental perceptual limitation, documented extensively in psychology research, profoundly affects interface design where page changes, notifications, and moving elements may go unnoticed. Understanding the causes—weak movement cues and limited attention capacity—enables designers to prevent change blindness through strategic design choices that direct attention appropriately.

## Key Takeaways

- **Change blindness definition** — people fail to notice changes in scenes when they occur outside the region receiving focal attention, a robust phenomenon even when people are forewarned.
- **Root cause: weak movement cues** — change blindness occurs when movement signals are absent or masked; screen flickers (page loads, UI updates) eliminate motion as a change indicator, requiring users to compare before/after versions mentally.
- **Competition for attention** — changes can fail to be noticed when competing with other visual movements; in magical illusions and UI design, one change attracts eye movement while blocking detection of simultaneous changes elsewhere.
- **Context-dependent UI changes** — when user actions trigger changes spread across multiple screen regions, users focus on the expected result area, missing unexpected changes elsewhere; hamburger menu actions exemplify this problem.
- **Prevention techniques** — make one change at a time, group simultaneous changes in the same screen region, use animation to signal change, dim unchanged areas, and display floating elements near user attention focus.

## Quotes

> Change blindness refers to people's tendency to ignore changes in a scene when they occur in a region that is far away from their focus of attention.

> Change is and has always been important for humans — it can convey essential information about our environment.

> Change blindness occurs when movement as a cue for change is weak or completely absent.

## Concepts

- [[Perception]] — human sensory processing and attention; change blindness demonstrates limitations in how thoroughly people observe visual information, with attention as a critical mediator.
- [[Visual Hierarchy]] — the mechanism directing focus to salient elements; understanding attention limitations helps designers ensure important changes are noticed through appropriate prominence.
- [[User Interface]] — the craft of creating effective human-computer interactions; awareness of change blindness enables better design choices around notifications, menu animations, and dynamic content.
