# Designing With and For AI

## When to open this theme

Designing an AI feature or chatbot, using AI in the design process, prompting, or reasoning about what these systems get wrong.

Two distinct branches deliberately kept together: AI as a design material, and AI as a tool in the workflow.

## Concepts (11)

- [[Artificial Intelligence]] (22 sources) : the mechanism before the capability, designing AI experiences, adopting AI in a team
- [[AI in Design]] (18 sources) : where AI earns its place in design work, where it fails, and what it changes for the designer
- [[Generative AI]] (18 sources) : how it is trained and what that implies, failure modes, and where it adds product value
- [[AI Chatbots]] (13 sources) : deciding whether chat is right at all, five qualities to design for, known conversational limits
- [[Prompt Engineering]] (12 sources) : structuring the prompt, how prompt shape determines conversation shape, context design
- [[Large Language Model]] (11 sources) : how the model is built, natural language as interface, specialising rather than using raw
- [[AI Limitations]] (10 sources) : the mechanism behind each failure, sycophancy, and where the tools fail task by task
- [[AI Product Design]] (8 sources) : starting from the user problem, scoping narrowly, designing for probabilistic output
- [[AI in User Research]] (8 sources) : where AI helps, where it fails, and the open disagreements between sources
- [[AI Agent]] (7 sources) : judging whether an agent is useful, the want-attempt gap, agents as users of your interface
- [[Voice Interfaces]] (6 sources) : discoverability without a screen, the cost of listening, and which tasks voice suits
