# Structure, Navigation and Findability

## When to open this theme

Organising content, designing navigation or menus, naming things, or diagnosing why users cannot find what exists.

Covers both the backstage structure and the visible navigation that exposes it, plus search and information scent. The place to start for any B2B or complex-app navigation question.

- [[Information Architecture]] (67 sources) : structure versus navigation, labels, hierarchy depth, search, and findability failures
- [[Navigation Design]] (37 sources) : menu patterns, visible versus hidden, wayfinding, back navigation, long pages, mobile
- [[Content Strategy]] (21 sources) : writing for scanning, length under mobile constraint, and organising and labelling content
- [[Web Usability]] (16 sources) : convention as default and deviation as cost, layout, links, trust, speed, forms
- [[Information Seeking]] (15 sources) : designing for task type, results-page scanning, and the vocabulary problem
- [[Discoverability]] (13 sources) : signifiers for invisible interactions, modes, and testing whether people find things
- [[Information Scent]] (12 sources) : writing labels that carry scent, and not promising what the click will not deliver
- [[Search]] (10 sources) : precision and recall, the search interface, suggestions, and how AI changes retrieval
- [[Menu Design]] (8 sources) : choosing a menu shape, mega menus, dropdown hierarchy, labels and touch targets
- [[Card Sorting]] (8 sources) : study variants, reading the results, and pairing it with tree testing
- [[Intranet Design]] (7 sources) : the persistent internal-tool mistakes, plus crisis IA and post-merger structure
- [[Complex Applications]] (5 sources) : locating where complexity actually sits, studying the domain, three user types
