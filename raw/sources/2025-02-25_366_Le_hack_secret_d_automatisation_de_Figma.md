La première SAP est très simple, c'est de lancer la console Figma. Si vous êtes sur Mac, vous pouvez appuyer sur « Command K », ça va afficher la console directement. Sinon, vous pouvez aller dans le menu Figma, puis dans le petit menu « Action » et faire « Show Hide Console ». Et sinon, vous pouvez également faire un clic droit « Plugin Développement Show Hide Console » pour afficher la console. La première chose, la première problématique à laquelle on va se confronter dans cette console, c'est que par défaut on n'a pas le droit de coller du code dans cette console, pour des raisons de sécurité. Et donc forcément ça c'est super embêtant, parce que si on veut copier notre code depuis un modèle de langage comme ChatJPT pour le mettre dans Figma et qu'on n'a pas le droit de le coller, ça va être compliqué. C'est très simple à débloquer, il suffit de taper « Allow Pasting » directement dans la console et désormais vous serez autorisé à coller du contenu, à coller du texte dedans. Pour avoir la commande, essayez tout simplement de coller quelque chose dans la console et là vous allez voir un petit message d'erreur apparaître qui vous dit « Ok, tapez « Allow Pasting » » et vous tapez ça et ce sera bon.
